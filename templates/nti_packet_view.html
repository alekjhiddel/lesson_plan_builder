Dear {{ packet.parent_name }},

School is closed, but learning continues at home! Here are some activities for {{ packet.student.first_name }}.

✅ How to Use This Packet:
  • Pick 3-5 activities per day (you don't have to do ALL of them)
  • Do activities when {{ packet.student.first_name }} is calm and happy
  • Keep it short — 10-15 minutes per activity is great!
  • Take breaks between activities
  • It's okay to stop if {{ packet.student.first_name }} gets frustrated
  • ANY attempt counts — we celebrate trying!
💬 Communication Tips:

{% if packet.student.communication_mode == 'pecs' %} Use {{ packet.student.first_name }}'s picture communication book/board during activities. Help them point to or hand you pictures to make choices and requests. {% elif packet.student.communication_mode == 'device' %} Keep {{ packet.student.first_name }}'s communication device nearby during activities. Model using it to make requests and comments. {% elif packet.student.communication_mode == 'gestures' %} Watch for {{ packet.student.first_name }}'s gestures and sounds during activities. Respond to any communication attempts — pointing, reaching, and sounds all count! {% else %} Talk with {{ packet.student.first_name }} during activities. Ask simple questions and wait for answers. Praise all attempts! {% endif %}

⭐ Tips for Success:
  • Do activities at a table or quiet area (less distractions)
  • Praise every attempt! ("Good trying!" "Nice work!")
  • If something is too hard, make it easier or skip it
  • Use items you already have at home — don't buy anything new
  • Hand-over-hand help is okay!
  • Have fun! Learning should feel good 😊
